# 프로젝트명: 곡예 (가제) - 레벨 에디터(Editor) 기능 설계

이 문서는 '곡예'의 스테이지 제작을 위한 커스텀 레벨 에디터의 핵심 기능 명세입니다. 불필요하고 복잡한 기능은 배제하고, 직관적인 **오브젝트 배치, 데이터 관리, 즉각적인 테스팅, 그리고 최종 빌드**라는 기본기에 충실하게 설계되었습니다.

---

## 1. 오브젝트 배치 및 속성 편집 (Placement & Edit)
기본적인 레벨 조립을 위한 핵심 도구입니다.

*   **오브젝트 팔레트 (Palette):**
    *   앵커(고정, 파괴, 이동형), 방해 요소(데이터 스파크, 레이저), 점수 아이템, 바람 구역 등 인게임 프리팹을 목록화하여 마우스 드래그 앤 드롭으로 맵에 배치합니다.
*   **트랜스폼(Transform) 제어 및 그리드 스냅:**
    *   단축키를 활용한 이동/회전/스케일 조정과, 일정한 간격으로 배치할 수 있는 그리드 스냅(Grid Snap) 기능을 제공합니다.
*   **개별 속성 설정 (Inspector):**
    *   배치된 오브젝트를 선택해 앵커의 대기 시간, 장애물의 이동 속도, 돌풍의 세기 등 세부 파라미터를 에디터 상에서 직접 수정합니다.

## 2. 씬 데이터 입출력 (Save & Load)
작업한 레벨 데이터를 영구적으로 보관하고 관리합니다.

*   **파일 저장 (Save):**
    *   현재 배치된 모든 오브젝트의 Transform 정보와 속성 파라미터를 JSON 형태의 가벼운 씬(Scene) 파일로 직렬화하여 저장합니다.
*   **파일 불러오기 (Load):**
    *   저장해둔 씬 데이터 파일을 목록에서 선택해 로드하여 수정 작업을 이어갈 수 있습니다.

## 3. 에디터 플레이 및 테스팅 (Play in Editor)
레벨 디자인 과정에서 밸런스와 난이도를 즉시 점검합니다.

*   **즉시 플레이 전환 (Play/Stop):**
    *   별도의 클라이언트 실행 없이 에디터 내에서 단축키(Play 버튼) 하나로 게임 로직을 가동시켜 맵을 직접 플레이합니다.
*   **지정 위치 스폰 (Play from Here):**
    *   맵이 길어질 경우를 대비해, 시작 지점이 아닌 레벨 디자이너가 원하는 특정 위치(현재 카메라 뷰포트 중앙 등)에서 즉시 플레이어를 스폰하여 테스트하는 기능을 지원합니다.

## 4. 빌드 및 데이터 익스포트 (Build & Export)
완성된 씬을 실제 게임 구동 환경으로 내보냅니다.

*   **게임용 데이터 추출 (Export):**
    *   에디터 전용 디버그 데이터나 헬퍼 기즈모 정보는 제외하고, 인게임 클라이언트가 읽어들일 수 있는 최적화된 형식으로 레벨 데이터를 익스포트합니다.
*   **클라이언트 빌드 연동 (Build):**
    *   작업이 완료된 씬들을 순서대로 묶어, 게임 클라이언트가 인식하는 스테이지 테이블에 등록하거나 실행 가능한 빌드로 패키징하는 기능을 제공합니다.
